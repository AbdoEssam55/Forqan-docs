## Scope
- Startup backfill of bootstrap checkpoint passes for students with reached progress.
- Case-insensitive checkpoint snapshot matching.
- Memorization draft vs submit both enforce the same sard gate.

## Test pages
- API / Swagger or tenant API client against a tenant DB

## Test scenarios
- Mid-Qur'an students get bootstrap passes on API start so hifz submit is not blocked by early checkpoints.
- Ranges past the real pending boundary still fail on both draft and submit.
