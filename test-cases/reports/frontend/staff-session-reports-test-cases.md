# Staff session reports — Frontend Test Cases

## Metadata

- Project: `alforqan`
- Feature: `reports`
- Layer: `frontend`
- Routes: `/{locale}/{tenantSlug}/reports/sessions`
- Related code: `src/app/[locale]/(tenant)/[tenantSlug]/reports/reports-hub-content.tsx`, `src/app/[locale]/(tenant)/[tenantSlug]/reports/sessions/page.tsx`, `src/app/[locale]/(tenant)/[tenantSlug]/reports/sessions/layout.tsx`, `src/features/alforqan/reports/staff-session-reports-page.tsx`, `src/features/alforqan/reports/staff-report-export-dialog.tsx`, `src/features/alforqan/reports/staff-session-reports-utils.ts`, `src/features/alforqan/reports/staff-report-mistakes-cell.tsx`, `src/lib/api/tenant-client.ts`, `src/types/staff-session-reports.ts`
- Related docs: `docs/technical/tenant/staff-session-reports-guide.md`, `docs/technical/auth/permissions-and-signalr-guide.md`

## Scope

- Staff hub tile and `/reports/sessions` with three tabs (Hifz, Revision, Sard).
- Shared sticky toolbar with URL-synced filters.
- DataTable (not cards); KPI strip and honor-board export (PDF / Excel / CSV).
- Parents blocked; Hifz/Revision gated by `ViewMemorizationReportsClaim`; Sard tab gated by `ViewNarrationReportsClaim`.
